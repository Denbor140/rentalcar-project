## 📜 About

**Rental Car** is a web application designed for car rental

It helps users:

- view all available cars for rent
- filter cars by brand, price and mileage
- filling out a car rental form

---

## ⚡ Features

- 🚗 Browse all available rental cars
- 🔍 Filter cars by brand, price, and mileage
- 📋 Car rental request form with validation
- 🔔 Real-time notifications (Toaster)

---

## 🧰 Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **State Management:** Zustand
- **Data Fetching:** React Query
- **Forms:** Formik + Yup
- **Styling:** CSS Modules
- **Notification:** Toaster
